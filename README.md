# Acompanhamento do Desenvolvimento da Escrita de Redações dos Alunos do Ensino Médio

Projeto de extensão desenvolvido na disciplina **Interação Humano-Computador (IHC)**, da Universidade Federal do Ceará (UFC), com foco na investigação de dificuldades relacionadas ao ensino, à produção e ao acompanhamento de redações no Ensino Médio.

## 📌 Sobre o projeto

O projeto surgiu a partir da investigação dos desafios enfrentados por professores e estudantes durante o processo de produção textual.

Entre as dificuldades identificadas, destacam-se o tempo necessário para corrigir redações, a organização das atividades dos alunos e o acompanhamento da evolução da escrita ao longo do tempo.

A partir dessa investigação, foram desenvolvidas atividades de pesquisa e concepção de uma solução digital, culminando em um **protótipo interativo de interface no Figma**.

## 🎯 Objetivos

- Investigar as principais dificuldades de professores e estudantes relacionadas à produção de redações.
- Compreender as necessidades dos usuários por meio de atividades de pesquisa.
- Analisar soluções existentes relacionadas ao problema investigado.
- Definir requisitos para uma possível solução digital.
- Projetar uma interface considerando os princípios de Interação Humano-Computador.

## 🔎 Metodologia

Durante o desenvolvimento do projeto, foram realizadas atividades como:

- Entrevistas com professores de redação do Ensino Médio.
- Observação de aulas e atividades com estudantes.
- Análise dos dados coletados durante a pesquisa.
- Análise comparativa de soluções semelhantes (*benchmarking*).
- Elaboração de personas e cenários de uso.
- Levantamento de requisitos.
- Desenvolvimento de um protótipo interativo no Figma.

## 💡 Resultados

A pesquisa permitiu identificar dificuldades relacionadas à correção, à organização e ao acompanhamento das redações, além de desafios enfrentados pelos estudantes durante a produção textual.

Com base nos dados levantados, o projeto avançou para a concepção de uma interface que representa uma possível solução para as necessidades identificadas.

O resultado é um protótipo interativo que permite visualizar a proposta de interface e explorar a solução planejada, sem representar necessariamente um sistema implementado ou funcional em produção.
